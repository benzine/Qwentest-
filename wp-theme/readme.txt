A premium consulting theme with smooth scrolling, GSAP animations, Three.js effects, and a complete Studio Backoffice for admin-only content management.

== Description ==

Apex Consulting is a pixel-perfect WordPress theme converted from a modern React application. It features:

* **Smooth Scrolling** - Powered by Lenis for buttery-smooth scroll experience
* **GSAP Animations** - Scroll-triggered animations using ScrollTrigger
* **Three.js Effects** - Interactive particle field in the hero section
* **Studio Backoffice** - Admin-only content management system (not visible to public)
* **Responsive Design** - Fully responsive across all devices
* **Accessibility Ready** - WCAG 2.1 AA compliant
* **SEO Optimized** - Semantic HTML structure with proper heading hierarchy
* **Performance Optimized** - Lazy loading, optimized assets, minimal bundle size

== Sections ==

1. Hero - Full-screen hero with Three.js particle background
2. About - Company story with magnetic word animations
3. Services - Grid layout with geometric shapes
4. Process - Timeline with progress indicator
5. Case Studies - Client success stories with metrics
6. Insights - Blog posts with category filters
7. Team - Constellation-style team layout
8. Contact - AJAX contact form with validation
9. Footer - Journey map navigation

== Studio Backoffice ==

The theme includes a comprehensive backoffice system accessible only to administrators:

* Access via WordPress Admin > Studio menu
* Tabbed interface for easy navigation
* Real-time save with AJAX
* Frontend edit mode for quick updates
* Repeater fields for services and team members
* Color customization options

== Installation ==

1. Download the theme ZIP file
2. Go to WordPress Admin > Appearance > Themes
3. Click "Add New" > "Upload Theme"
4. Choose the ZIP file and click "Install Now"
5. Activate the theme
6. Configure settings via Appearance > Studio

== Frequently Asked Questions ==

= How do I access the Studio Backoffice? =
Log in as an administrator and navigate to the "Studio" menu in the WordPress admin sidebar.

= Can I edit content from the frontend? =
Yes! When logged in as an admin, click the "Edit Mode" button in the bottom-right corner of the frontend to enable click-to-edit functionality.

= Is the theme compatible with page builders? =
The theme is designed to work standalone but is compatible with Gutenberg blocks. Page builder compatibility can be added via child theme.

= How do I customize the colors? =
Go to Studio > Styling tab to change primary and accent colors. Additional color customization is available in the Customizer.

= Does the theme support multiple languages? =
Yes, the theme is translation-ready with all strings wrapped in i18n functions. Use WPML or Polylang for multilingual sites.
